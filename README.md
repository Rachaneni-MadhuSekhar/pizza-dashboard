📌 Project Overview
This project is an interactive Pizza Sales Dashboard created using Power BI to analyze pizza sales performance, customer ordering patterns, and product profitability.
The dashboard helps in understanding:
Total sales performance
Average pricing and tax analysis
Sales trends by month
Best-performing pizza categories
Top-selling pizza types
Profit contribution analysis
📊 Dashboard Features
🔹 KPI Cards
The dashboard includes important business metrics such as:
Total Sales: 899.65K
Average Price: 16.49
Total Quantities Sold: 50K
Average Tax Amount: 1.68
Total Orders: 48.62K
🔹 Visualizations Used
Bar Chart → Total Quantity by Category
Horizontal Bar Chart → Top 5 Pizza Types
Line Chart → Total Sales by Month
Pie Chart → Profit by Pizza Type
Slicer → Pizza Size Filter
📈 Key Insights
Classic pizzas recorded the highest quantity sold.
Thai Chicken pizza generated the highest profit contribution.
Sales showed strong performance during mid-year months.
Large-sized pizzas contributed significantly to overall sales.
